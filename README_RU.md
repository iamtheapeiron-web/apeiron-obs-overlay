# APEIRON OBS Overlay

**APEIRON OBS Overlay** — лёгкая Windows-утилита для OBS Studio: показывает состояние микрофона поверх игры и добавляет глобальное управление микрофоном.

> **Текущая версия:** `v0.2.0-beta.1`  
> **Платформа:** Windows 10/11 x64  
> **Статус:** Beta, без цифровой подписи

## Возможности

- Глобальная клавиша **Mute / Unmute**.
- **Hold Mode**: временно переключает микрофон в противоположное состояние, пока клавиша удерживается, и возвращает исходное после отпускания.
- Настраиваемый индикатор состояния микрофона.
- Отдельные правила отображения для обычного переключения и Hold Mode.
- Настройка положения, размера, формы, прозрачности и цветов.
- Подключение к встроенному OBS WebSocket с явным выбором аудиоисточника.
- Работа из системного трея и автозапуск вместе с Windows.
- Предупреждение, если OBS и оверлей запущены с разными правами.
- Защита от запуска двух экземпляров.
- Шифрование сохранённого OBS WebSocket-пароля для текущего пользователя Windows.

## Быстрая настройка

1. В OBS откройте **Tools → WebSocket Server Settings**.
2. Включите WebSocket server.
3. Запустите `APEIRON OBS Overlay.exe`.
4. На вкладке **OBS** укажите Host / Port / Password и нажмите **Connect / refresh**.
5. Явно выберите аудиоисточник, которым должно управлять приложение.
6. На вкладке **Controls** назначьте клавиши Mute / Unmute и Hold Mode.
7. Нажмите **Save / Apply**.

## Оверлей и захват OBS

Оверлей предназначен для самого стримера. **Game Capture** / **Window Capture** обычно его не захватывают, но **Display Capture** может. Перед реальным стримом сделайте короткую локальную запись.

## Hold Mode

Mute / Unmute меняет постоянное базовое состояние микрофона. Hold Mode временно применяет противоположное состояние и после отпускания возвращает базовое.

Для Hold Mode можно:

- использовать обычные правила оверлея;
- держать индикатор видимым всё время удержания;
- полностью скрыть отображение Hold Mode.

## Запуск от администратора

Если OBS работает от администратора, Windows может блокировать глобальные клавиши от приложения с обычными правами. APEIRON OBS Overlay обнаруживает такую ситуацию и предлагает перезапуститься с теми же правами.

## Приватность

Приложение подключается только к указанному OBS WebSocket. Сохранённый пароль шифруется для текущего пользователя Windows. **Copy diagnostics не включает пароль.**
