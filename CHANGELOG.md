# Changelog

## v0.2.0-beta.1 — 2026-10-09

First public beta.

- Added global Mute / Unmute and Hold Mode controls.
- Added configurable microphone-state overlay.
- Added separate display behavior for normal changes and Hold Mode.
- Added OBS WebSocket connection and explicit input selection.
- Added placement mode, tray mode and Windows startup support.
- Added privilege-mismatch detection and administrator restart flow.
- Added single-instance protection.
- Added per-user encrypted password storage.
- Improved hotkey edge handling and Hold/Toggle conflict resolution.
- Improved reconnect behavior and restoration after Hold Mode.
- Added Windows icon, manifest and version resources.
